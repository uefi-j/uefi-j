# Manifesto UEFI-J

Computadores evoluem.

Firmware muda.

Plataformas desaparecem.

Mas software histórico continua sendo parte da cultura digital.

O UEFI-J existe para preservar décadas de computação x86,
permitindo que sistemas clássicos coexistam com hardware moderno.

Compatibilidade não é nostalgia.

Compatibilidade é preservação.
